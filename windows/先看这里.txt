轻压 v1.1 · Windows 压缩 / 解压
==================================================

拖进来就能压缩、解压。Windows 上打的 zip 中文不会乱码，带密码的包会弹框问你。
适用 Windows 10 及以上，64 位。不用另外安装 Python。


【安装】只做一次

  1. 把压缩包解压到一个不会被删掉的文件夹（比如「文档\轻压」）

  2. 双击 QingYa.exe

  3. 如果弹出「Windows 已保护你的电脑」：
     点「更多信息」，再点「仍要运行」。
     （这个程序没有买微软的签名，所以系统会先拦一下）

  4. （推荐）打开轻压，点「设置」→「添加到右键菜单」。
     以后在文件上右键就能「用轻压压缩」或「用轻压解压」。
     想让双击 zip 直接用轻压：点「打开系统默认应用设置」，
     把 .zip 的默认应用选成轻压。


【解压】

  把压缩包拖进窗口左边，或拖到 QingYa.exe 上。

  · 默认解压到压缩包旁边。只有一个文件夹就直接放出来，零散文件会装进同名文件夹
  · 重名不会覆盖，自动变成「资料 2」
  · 分卷（.001 / .part1.rar）拖任意一卷进来都行，会自动找齐
  · 想先看看里面有什么：点「浏览压缩包」。文件名还是乱码时，右上角换一种编码


【压缩】

  把文件或文件夹拖进窗口右边。中间可以选：

  格式      ZIP 最通用；7Z 更小；TAR.GZ 给服务器
  压缩率    一般用「标准」。图片、视频本身已经压缩过，选「快速」省时间
  密码      ZIP 用 AES-256。对方如果只用 Windows 自带解压，可能打不开，
            需要本工具 / 7-Zip / Bandizip / WinRAR
  分卷      邮件附件选 25 MB，FAT32 U 盘选 4 GB

  .DS_Store、Thumbs.db 这类系统文件默认不会打进包里。


【常见问题】

· 提示「Windows 已保护你的电脑」
  → 按安装第 3 步，点「更多信息」→「仍要运行」。

· 带密码的 RAR 解不开
  → 安装包里应该有 7z.exe，和 QingYa.exe 放在同一个文件夹。不要只把 exe 单独拷走。

· 文件名还是乱码
  → 点「浏览压缩包」，右上角把编码改成「简体中文（GBK）」，再点「全部解压」。

· 右键里找不到「用轻压」
  → 轻压 → 设置 →「添加到右键菜单」。如果菜单被其他软件占用，重启资源管理器或注销一次。


【说明】

程序完全在你自己电脑上运行，不联网，不上传任何文件。
记住的解压密码保存在 Windows 凭据管理器里。
解压和压缩都先写到临时目录，成功才搬出来；取消或失败不会留下半截文件，也不会覆盖已有文件。
