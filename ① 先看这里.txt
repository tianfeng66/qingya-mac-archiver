轻压 v1.0 · Mac 压缩 / 解压工具
==================================================

拖进来就能压缩、解压。Windows 发来的 zip 中文不乱码，带密码的包会弹框问你。
适用 macOS 13 及以上，Intel / Apple 芯片都行，不用装别的东西。


【安装】只做一次，约 30 秒

  1. 把「轻压.app」拖进「应用程序」文件夹

  2. 打开「终端」（按 ⌘+空格，输入"终端"回车），复制下面这行粘贴进去，回车：

       xattr -cr /Applications/轻压.app

     （没有任何输出就是成功了。这一步是解除系统对"网上下载的 App"的拦截，
       因为这个工具没有买苹果的开发者签名）

  3. 双击打开，在程序坞的图标上右键 →「选项」→「在程序坞中保留」

  4. （推荐）菜单「轻压 → 设置 → 系统集成」点「设为压缩包的默认打开方式」，
     以后双击 zip / rar / 7z 就直接解压。


【解压】

  把压缩包拖进窗口左边，或拖到程序坞图标上，或直接双击压缩包。

  · 解压到压缩包旁边。只有一个文件夹就直接放出来，零散文件会装进同名文件夹
  · 重名不会覆盖，自动变成「资料 2」
  · 分卷（.001 / .part1.rar）拖任意一卷进来都行，会自动找齐
  · 想先看看里面有什么：工具栏「浏览压缩包」，双击文件可直接打开预览


【压缩】

  把文件或文件夹拖进窗口右边。窗口中间可以选：

  格式      ZIP 最通用（发给 Windows / 手机用它）；7Z 更小；TAR.GZ 给服务器
  压缩率    一般用「标准」；图片视频本身已经压缩过，选「快速」省时间
  密码      ZIP 用 AES-256 加密。对方用 Windows 自带解压可能打不开，
            需要 7-Zip / Bandizip / WinRAR
  更多      分卷（邮件附件 25 MB、FAT32 U 盘 4 GB）、多个项目分别压缩

  .DS_Store 这类 Mac 专属的隐藏文件默认不会打进包里。


【常见问题】

· 提示"已损坏，无法打开"
  → 没做安装第 2 步，做一下就好。

· 带密码的 RAR / 7z 解不开
  → 系统自带引擎不支持这种加密。装一次 7-Zip 就行：
    终端运行  brew install sevenzip  ，然后重启轻压。

· 文件名还是乱码
  → 「浏览压缩包」打开它，右上角换一种文件名编码，再点「全部解压」。

· 访达右键里找不到「用轻压压缩」
  → 设置 → 系统集成 → 打开键盘快捷键设置 →「服务」→ 在「文件和文件夹」里勾上。


【说明】

程序完全在你自己电脑上运行，不联网，不上传任何文件。
记住的解压密码保存在系统钥匙串里。
